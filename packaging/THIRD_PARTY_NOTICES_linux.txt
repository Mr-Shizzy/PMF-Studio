atracdenc  (tools/atracdenc)
----------------------------
An open ATRAC3plus encoder by Daniil Cherednik and contributors: https://github.com/dcherednik/atracdenc
Licence: GNU Lesser General Public License version 2.1 (licenses/atracdenc-LICENSE-LGPL-2.1.txt).
Source:  the upstream commit named in source/atracdenc/BASE_COMMIT.txt, plus four small patches made for PMF Studio (frame-size,
         tonal-trim, adaptive-precision, windows-no-libsndfile - the last one only replaces the sound-file reader and is used on
         every system), which are all included in source/atracdenc/ (the patches are under the same LGPL-2.1 licence).
         source/atracdenc/README.txt gives the build commands. The program you have was built from that source with those commands
         (cmake, g++ on Linux, linked statically with the GNU C library, which is under the LGPL 2.1: https://www.gnu.org/software/libc/ ).
         You can rebuild atracdenc from that source and put your own build in tools/ to replace it.

--------------------
Drag and drop of files onto the window, for Tk on X11 (and on Wayland desktops, through XWayland). tkdnd 2.9.5 by Georgios Petasis:
https://github.com/petasis/tkdnd
Licence: the Tcl/Tk-style licence (permissive, compatible with the GPL): licenses/tkdnd-LICENSE.txt.
Build:   made by the PMF Studio project from the official source (packaging/linux/build_tkdnd.sh in the repository: tkdnd 2.9.5 with the

         licenses/tcl-LICENSE.txt and licenses/tk-LICENSE.txt. It uses the system's libX11.

Tk with font support and the system libraries inside _internal
--------------------------------------------------------------
The Python this program is packed with has a Tk that cannot use the computer's fonts (it can only draw with one plain bitmap font). So
PMF Studio uses a Tk 9.0.4 built by the PMF Studio project from the official source (packaging/linux/build_tk_xft.sh in the repository: the
same Tk version, built with font support; the source tarball hashes and the Ubuntu header packages it was built against are pinned in that
script). Tk's licence is the BSD-style Tcl/Tk licence (licenses/tk-LICENSE.txt).
For font drawing and the window system that Tk then needs, the program carries copies of these system libraries (taken from the Ubuntu 24.04
machine it was built on) in its _internal folder: libX11 (with libXau, libXdmcp, libbsd, libmd), libXft, libXrender, fontconfig, FreeType
(under the FreeType Licence), expat, libpng, brotli, zlib and bzip2. All are free software under permissive licences (MIT, BSD, zlib, libpng,
FreeType). Their licence texts, as the Ubuntu packages carry them, are in licenses/bundled-system-libraries.txt.
