FFmpeg  (tools/ffmpeg)
----------------------
Version: 9.0.2 ("tools/ffmpeg -version" prints it; tools/ffmpeg-build.txt names the SHA-256 of the program).
Build:   made by the PMF Studio project itself, from the official source tarballs, as one static program with these libraries:
         x264 (H.264 encoder, GPL 2 or later), LAME 3.100 (MP3 encoder, LGPL 2.1), dav1d 1.5.4 (AV1 decoder, BSD 2-clause) and
         zlib 1.3.1 (zlib licence). FFmpeg's own code is used as it is, unchanged.
Licence: GNU General Public License version 2 or later (this build includes the GPL library x264). The licence texts of FFmpeg and of
         every library inside are in licenses/ (ffmpeg-COPYING.GPLv2.txt, ffmpeg-COPYING.LGPLv2.1.txt, ffmpeg-LICENSE.md,
         x264-COPYING.txt, lame-COPYING.txt, dav1d-COPYING.txt, zlib-LICENSE.txt).
Source:  everything needed to build it again is in the file PMF-Studio-ffmpeg-source.tar.xz, attached to the same release as this
         program: the exact source tarballs of FFmpeg (with its signature), x264, LAME, dav1d and zlib, and the build script
         (build_ffmpeg.sh, also in the PMF Studio repository under packaging/linux/). The same sources are published by their
         projects: https://ffmpeg.org/releases/ffmpeg-9.0.2.tar.xz , https://code.videolan.org/videolan/x264 (commit

         https://zlib.net/ .


atracdenc  (tools/atracdenc)
----------------------------
An open ATRAC3plus encoder by Daniil Cherednik and contributors: https://github.com/dcherednik/atracdenc
Licence: GNU Lesser General Public License version 2.1 (licenses/atracdenc-LICENSE-LGPL-2.1.txt).
Source:  the upstream commit named in source/atracdenc/BASE_COMMIT.txt, plus four small patches made for PMF Studio (frame-size,
         tonal-trim, adaptive-precision, windows-no-libsndfile - the last one only replaces the sound-file reader and is used on
         every system), which are all included in source/atracdenc/ (the patches are under the same LGPL-2.1 licence).
         source/atracdenc/README.txt gives the build commands. The program you have was built from that source with those commands
         (cmake, g++ on Linux, linked statically with the GNU C library, which is under the LGPL 2.1: https://www.gnu.org/software/libc/ ).
         You can rebuild atracdenc from that source and put your own build in tools/ to replace it.
